# Learn AI Law

A personal, self-contained study console for a 6-week study program covering AI contracts, intellectual property, regulation, and Responsible AI — written for an Enterprise Architect audience.

**Not legal advice.** Study material only.

## What's here

- `spa/index.html` — the study console itself: a single-page app (no build step, no external dependencies beyond Google Fonts) with a knowledge base, quiz bank, glossary, and case tracker. Open it directly in a browser or serve the `spa/` folder as a static site.
- `assets-src/` — source material used to build the console: Gamma deck outlines, NotebookLM prompts, and infographic briefs.
- `prompts/` — reusable prompt templates for studying (Socratic examiner, issue-spotter, redline assist, translation, briefing).

## Running locally

Open `spa/index.html` in any browser, or serve the folder:

```
npx serve spa
```
